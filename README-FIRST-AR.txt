AnswerForU Mobile v3.3.0 — API CONNECTED SOURCE
==============================================

ده مشروع React Native / Expo كامل (سورس)، مش APK جاهز ولا ملف موقع ويب.
المصدر: تطوير نسخة Mobile v3.2.0 باستخدام API موقع AnswerForU v6.1.49.

التشغيل على Windows:
1. فك ZIP في مجلد مستقل.
2. تأكد أن Node.js حديث (يفضل Node 24 LTS).
3. شغّل RESET-AND-RUN.bat (npm install و Expo).
4. جرّب Android باستخدام Expo Go أو Development Build حسب توافق SDK.
5. شغّل TEST-BUNDLE.bat للتأكد من تجميع Android JS قبل EAS APK/AAB.
6. ملف BUILD-PREVIEW-APK.bat يعمل طلب Build عبر EAS ويتطلب إعداد حساب Expo.

المصدر الموحد:
- https://answerforu.com/api هو الـ Backend الوحيد لكل الموقع والموبايل.
- القاموس /api/glossary والتعلم /api/content/learn من قاعدة البيانات.
- التصفح للزائر متاح، وعمليات الكتابة والحساب تتطلب تسجيل الدخول.
- لا بيانات مستخدمين أو نسخة SQL داخل التطبيق.

الجديد في 3.3.0:
- تصفح كزائر، وربط نفس حساب الموقع (JWT داخل Expo SecureStore).
- تعليم DB بالكامل: أدلة حياة، عملات الوجه والظهر، إشارات، اختبار، محلات، خدمات، تعليم، تحويلات.
- شاشة طلباتي: عرض، تصفية، سبب الرفض، وتعديل الإعلانات وطلبات التعديل.
- مراجعة إعلانات وطلبات تعديل للأدمن (الصلاحية تُفحص على السيرفر).
- تقليل التحميل عند فتح المجتمع إلى قسم الأماكن فقط بدل 6 طلبات متزامنة.
- عرض 24 كارت مبدئيًا مع «عرض المزيد» وتقليل البيانات العامة المتكررة بذاكرة تخزين مؤقت قصيرة.
- حفظ إضافات المجتمع والمنشورات والتقييمات عبر نفس API؛ لا إنشاء Backend موازٍ.

حدود ما تم التحقق منه:
- فحص صياغة JSX/JS لجميع ملفات السورس، وفحص الملفات وConfig تم محليًا.
- لم يتم اختبار Android APK على جهاز فعلي أو نجاح EAS Build؛ مطلوب TEST-BUNDLE.bat وتجربة الجهاز.
- ليس ضمانًا بمطابقة جميع شاشات موقع 6.1.49: شاشات CV/الدردشة/الإدارة الكاملة وبعض نماذج تعديل الصور ما زالت محدودة.
- صفحات الأماكن ترجع كل البيانات من API الموقع؛ Pagination حقيقي من السيرفر يحتاج توسيع API موقع الإنتاج لاحقًا.
- لا ترفع ZIP الموبايل إلى public_html؛ هذا مشروع مستقل للموبايل.
